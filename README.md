## Sobre o projeto

Em almoxarifados, lojas de ferragens e oficinas, contar e separar parafusos por tipo, tamanho e largura costuma ser um trabalho manual, lento e sujeito a erros, sem nenhum histórico do que foi separado.

O **ParaFlow** automatiza esse processo: o firmware (simulado no Wokwi) mede e conta os parafusos, envia os dados para uma API própria e o estoque por bitola aparece em um dashboard web e em um aplicativo mobile, com alertas e comando para ligar e desligar o separador.

## Funcionalidades

- Contagem automática de parafusos.
- Classificação por tipo, tamanho e largura.
- Dashboard web com os dados consolidados.
- Aplicativo mobile para acompanhar os dados.
- Histórico de contagens.
